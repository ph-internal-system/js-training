🌿 Thymeleaf サンプル セットアップ手順

「Thymeleaf」教材 第8章「まとめ：Spring Boot + MyBatis + Thymeleafで画面付きCRUDアプリを作る」の内容を、MyBatis編で作成したプロジェクトをそのまま流用しながら手元で動かすための手順です。

前提

「MyBatis」教材のセットアップ手順（mybatis-setup.html）を完了し、my-appプロジェクトが動作する状態になっていることが前提です。entity/Book.java・form/BookForm.java・service/BookService.java・mapper/BookMapper.java・BookMapper.xml・schema.sqlはすべてそのまま使い、画面表示に必要な部分だけを新しく追加します。

何を再利用し、何を追加するか

再利用（変更なし）entity/Book.java / form/BookForm.java / service/BookService.java / mapper/BookMapper.java / mapper/BookMapper.xml / schema.sql / application.properties / 既存のcontroller/BookController.java（REST API）
変更pom.xml（Thymeleafの依存関係を追加）
新規追加controller/BookViewController.java / templates/book-list.html / templates/book-form.html
既存のREST APIとURLが衝突しないようにする
既存のBookControllerは@RestController ＋ @RequestMapping("/books")でJSON APIを提供しています。同じ/booksに対して画面表示用の@Controllerを追加すると、Spring Bootが「どちらのControllerを使えばよいか判断できない」というエラー（マッピングの衝突）を起こします。そこでこの手順では、画面表示用のURLを/screen/booksという別のパスにして、両方を共存させます。

実装手順

① pom.xmlに依存関係を追加する

Thymeleafの依存関係を追加します。既存のSpring Web・Validation・H2 Database・MyBatisの依存関係はそのまま残します。

追加 
<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-thymeleaf</artifactId>
</dependency>

② controller/BookViewController.javaを新規作成する

src/main/java/com/example/myapp/controller/に、画面遷移用の新しいControllerを追加します（既存のBookController.javaはそのまま残します）。DB操作はBookServiceをそのまま呼び出すだけなので、MyBatis編からの変更は不要です。

新規：controller/BookViewController.java 
package com.example.myapp.controller;

import com.example.myapp.form.BookForm;
import com.example.myapp.service.BookService;
import jakarta.validation.Valid;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.validation.BindingResult;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.servlet.mvc.support.RedirectAttributes;

@Controller
@RequestMapping("/screen/books")
public class BookViewController {

    private final BookService bookService;

    public BookViewController(BookService bookService) {
        this.bookService = bookService;
    }

    @GetMapping
    public String list(Model model) {
        model.addAttribute("books", bookService.findAll());
        return "book-list";
    }

    @GetMapping("/new")
    public String newForm(Model model) {
        model.addAttribute("bookForm", new BookForm());
        return "book-form";
    }

    @PostMapping
    public String create(@Valid @ModelAttribute("bookForm") BookForm bookForm,
                          BindingResult bindingResult,
                          RedirectAttributes redirectAttributes) {
        if (bindingResult.hasErrors()) {
            return "book-form";
        }
        bookService.create(bookForm);
        redirectAttributes.addFlashAttribute("message", "登録しました");
        return "redirect:/screen/books";
    }

    @PostMapping("/{id}/delete")
    public String delete(@PathVariable Long id, RedirectAttributes redirectAttributes) {
        bookService.delete(id);
        redirectAttributes.addFlashAttribute("message", "削除しました");
        return "redirect:/screen/books";
    }
}
@Valid の対象クラスはMyBatis編のBookFormのまま
form/BookForm.javaにはSpring Boot編ですでに@NotBlank・@Minが付いているため、このクラス自体の変更は不要です。REST API版では検証エラー時に例外がスローされましたが、画面版ではBindingResultで結果を受け取り、エラーがあれば同じ入力画面に戻す、という違いに注意してください。

③ テンプレートを新規作成する

src/main/resources/templates/フォルダを作成し、以下の2ファイルを配置します。

新規：templates/book-list.html 
<!DOCTYPE html>
<html lang="ja" xmlns:th="http://www.thymeleaf.org">
<head>
  <meta charset="UTF-8">
  <title>本の一覧</title>
</head>
<body>
  <h1>本の一覧</h1>
  <p th:if="${message}" th:text="${message}" style="color:green;"></p>
  <a th:href="@{/screen/books/new}">新規登録</a>
  <table border="1" cellpadding="6">
    <tr>
      <th>タイトル</th>
      <th>著者</th>
      <th>価格</th>
      <th></th>
    </tr>
    <tr th:each="book : ${books}">
      <td th:text="${book.title}">タイトル</td>
      <td th:text="${book.author}">著者</td>
      <td th:text="${book.price}">価格</td>
      <td>
        <form th:action="@{/screen/books/{id}/delete(id=${book.id})}" method="post" style="display:inline;">
          <button type="submit">削除</button>
        </form>
      </td>
    </tr>
  </table>
</body>
</html>
新規：templates/book-form.html 
<!DOCTYPE html>
<html lang="ja" xmlns:th="http://www.thymeleaf.org">
<head>
  <meta charset="UTF-8">
  <title>本の登録</title>
</head>
<body>
  <h1>本の登録</h1>
  <form th:action="@{/screen/books}" th:object="${bookForm}" method="post">
    <div>
      <label>タイトル：<input type="text" th:field="*{title}"></label>
      <p th:if="${#fields.hasErrors('title')}" th:errors="*{title}" style="color:red;"></p>
    </div>
    <div>
      <label>著者：<input type="text" th:field="*{author}"></label>
      <p th:if="${#fields.hasErrors('author')}" th:errors="*{author}" style="color:red;"></p>
    </div>
    <div>
      <label>価格：<input type="number" th:field="*{price}"></label>
      <p th:if="${#fields.hasErrors('price')}" th:errors="*{price}" style="color:red;"></p>
    </div>
    <button type="submit">登録</button>
  </form>
  <a th:href="@{/screen/books}">一覧に戻る</a>
</body>
</html>

④ 動作確認

  1. VSCodeのターミナルで mvn spring-boot:run、または IDEの実行ボタンからメインクラスを実行する
  2. ブラウザで http://localhost:8080/screen/books にアクセスし、一覧画面が表示されることを確認する
  3. 「新規登録」リンクからフォーム画面に遷移し、タイトルを空欄のまま送信してバリデーションエラーが表示されることを確認する
  4. 正しく入力して登録し、一覧画面に「登録しました」というメッセージとともにリダイレクトされることを確認する
  5. 一覧の「削除」ボタンから、本が削除されて一覧が更新されることを確認する
おまけ
http://localhost:8080/test.html（REST API版）とhttp://localhost:8080/screen/books（Thymeleaf版）を見比べると、同じBookService・BookMapperを使いながら、JSONを返すAPIと画面を返すMVCの両方を1つのプロジェクトで共存させられることが確認できます。
