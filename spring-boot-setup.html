🍃 Spring Boot サンプル セットアップ手順

「Spring Boot」教材 第8章「まとめ：簡単なCRUD APIを作る」の内容を、実際に手元で動かすための手順です。

H2データベースについて

H2は、Javaアプリの中に組み込まれて動く「インメモリ（メモリ上だけで動く）データベース」です。MySQLのような別ソフトのインストールや、サーバーの起動が一切不要なため、動作確認だけが目的であれば最も手軽な選択肢です。

メリット
・別途DBサーバーのインストール・起動が不要
・Spring Initializrで依存関係に追加するだけで使える
・application.properties の設定だけで、アプリ起動と同時にDBも自動的に用意される
注意点
アプリを停止するとデータは消えます（メモリ上にしかないため、永続化はされません）。動作確認・学習用途には向きますが、本番運用やデータを残しておきたい用途には不向きです。

参考：本格的にDBを使う場合

実際にMySQL等のDBMSを使う場合は、以下が事前に必要になります。

  1. MySQLサーバーがインストール済みで、起動していること
  2. CREATE DATABASE mydb; のように、データベース（スキーマ）自体を事前に自分で作成しておくこと（Spring Bootが自動生成してくれるのは「テーブル」までで、「データベース」そのものは作ってくれません）
  3. それを踏まえて application.properties に接続先（URL・ユーザー名・パスワード）を設定する
今回は動作確認が目的のため、H2を使う方法で進めます。

実装手順

① 環境構築

  1. Spring Initializr（https://start.spring.io）でプロジェクトを作成する。
    ProjectMaven
    LanguageJava
    Groupcom.example
    Artifactmy-app
    Package namecom.example.myapp
    PackagingJar
    DependenciesSpring Web / Spring Data JPA / Validation / H2 Database

    ※ Group・Artifact・Package name は、教材内のコード例（com.example.myapp パッケージ、MyAppApplication.java）とそのまま一致するように設定しています。Packagingは組み込みTomcatを使うため「Jar」を選択します。

  2. ダウンロードしたZIPファイルを展開する（右クリック →「すべて展開...」→ 展開先フォルダを選んで実行）
  3. VSCodeで「ファイル → フォルダーを開く」から、展開したフォルダを開く
  4. src/main/resources/application.properties を作成し、以下を記述する。 
    # H2をメモリ上に作成する接続設定
spring.datasource.url=jdbc:h2:mem:testdb
spring.datasource.driver-class-name=org.h2.Driver
spring.datasource.username=sa
spring.datasource.password=

# エンティティに合わせてテーブルを自動作成・更新する
spring.jpa.hibernate.ddl-auto=update

# 実行されたSQLをログに表示する（学習中の確認に便利）
spring.jpa.show-sql=true

# H2の管理画面（ブラウザ）を有効にする（任意・データの中身を目視できて便利）
spring.h2.console.enabled=true
spring.h2.console.path=/h2-console

② サーバーサイドのコードを依存関係の順に作成

依存されている側（下位）から先に作ると、コンパイルエラーが出ずスムーズです。

  1. エンティティ … entity/Book.java
  2. Repository … repository/BookRepository.java
  3. 入力値クラス … dto/BookForm.java
  4. カスタム例外 … exception/ResourceNotFoundException.java
  5. Service … service/BookService.java
  6. Controller … controller/BookController.java
  7. グローバル例外ハンドラ … exception/GlobalExceptionHandler.java

※ ここでのentity/などは、com.example.myappパッケージの下に作るサブパッケージ（サブフォルダ）です。VSCodeでは、パッケージ名の部分を右クリック →「新しいフォルダー」で entity・repository・dto・service・controller・exception を作成し、それぞれのフォルダの中に対応するクラスを作成してください。各クラスの実装内容（package文・import文を含む）は、学習教材の「Spring Boot」テーマ 第8章「まとめ：簡単なCRUD APIを作る」を参照してください。

③ 動作確認

  1. 動作確認用の簡易画面 test.html を src/main/resources/static/ に配置する（中身は教材 第8章「⑦ 動作確認用の簡易画面」を参照）
  2. アプリを起動する。VSCodeのターミナルで mvn spring-boot:run、または IDEの実行ボタンからメインクラスを実行
  3. ブラウザで http://localhost:8080/test.html にアクセスし、各ボタン（一覧取得・詳細取得・新規登録・更新・削除）を試す
おまけ
http://localhost:8080/h2-console にアクセスすると、H2のデータ中身をブラウザから直接見ることもできます（JDBC URL欄に jdbc:h2:mem:testdb を入力して接続）。
