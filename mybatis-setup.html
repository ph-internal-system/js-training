🔗 MyBatis サンプル セットアップ手順

「MyBatis」教材 第8章「まとめ：MyBatisでCRUD APIを組み立てる」の内容を、Spring Boot編で作成したプロジェクトをそのまま流用しながら手元で動かすための手順です。

前提

「Spring Boot」教材のセットアップ手順（spring-boot-setup.html）を完了し、my-appプロジェクトが動作する状態になっていることが前提です。ここではゼロから作り直すのではなく、そのプロジェクトのJPA部分だけをMyBatisに置き換える形で進めます。

何を再利用し、何を変更するか

再利用（変更なし）controller/BookController.java / form/BookForm.java / exception/ResourceNotFoundException.java / exception/GlobalExceptionHandler.java / test.html / pom.xmlのSpring Web・H2・Validation部分 / application.propertiesのDB接続情報（spring.datasource.*）
変更pom.xml（JPA依存関係 → MyBatis依存関係）/ application.properties（spring.jpa.* → mybatis.*）/ entity/Book.java（JPAアノテーションを除去）/ service/BookService.java（呼び出し先をbookMapperに変更）/ MyAppApplication.java（@MapperScanを追加）
新規追加schema.sql / mapper/BookMapper.java / mapper/BookMapper.xml
削除repository/BookRepository.java
なぜapplication.propertiesの書き換えが必要か
spring.jpa.hibernate.ddl-auto=updateは、Hibernate（JPA）の自動設定クラスだけが読み込む設定です。pom.xmlからJPA依存を外すとHibernateの自動設定自体が有効化されなくなり、この設定は「誰にも読まれないテキスト」になってしまいます。MyBatisにはテーブルを自動生成する仕組みがないため、代わりにschema.sqlでテーブルを用意します。

実装手順

① pom.xmlを変更する

JPAの依存関係を削除し、MyBatisの依存関係を追加します。

変更前（削除） 
<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
変更後（追加） 
<dependency>
  <groupId>org.mybatis.spring.boot</groupId>
  <artifactId>mybatis-spring-boot-starter</artifactId>
  <version>4.0.1</version>
</dependency>

※ Spring Web・Validation・H2 Databaseの依存関係はそのまま残します。

バージョンはSpring Bootのバージョンに依存する
mybatis-spring-boot-starterのバージョンは、組み合わせるSpring Bootのバージョンによって対応状況が異なります。この教材のSpring Boot編はspring-boot-starter-parent 3.3.0を前提にしていますが、別のバージョンのSpring Bootを使う場合は、それに対応するmybatis-spring-boot-starterのバージョンを別途確認・指定してください。

② application.propertiesを変更する

変更前（削除） 
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
変更後（追加） 
# XMLマッピングファイルの置き場所
mybatis.mapper-locations=classpath:mapper/**/*.xml

# エンティティクラスの短縮名（型エイリアス）を使えるようにするパッケージ
mybatis.type-aliases-package=com.example.myapp.entity

# テーブルのスネークケースをJavaのキャメルケースに自動変換する
mybatis.configuration.map-underscore-to-camel-case=true

※ spring.datasource.*（H2の接続情報）とspring.h2.console.*はそのまま残します。

③ schema.sqlを新規作成する

src/main/resources/schema.sql を新規作成します。Spring Bootは、ORM（JPA/MyBatis）の種類に関係なく、起動時にこのファイルを自動実行してくれます。

CREATE TABLE book (
    id     BIGINT       PRIMARY KEY AUTO_INCREMENT,
    title  VARCHAR(255) NOT NULL,
    author VARCHAR(100) NOT NULL,
    price  INT          NOT NULL
);

④ entity/Book.javaからJPAのアノテーションを外す

MyBatisはアノテーションの有無に関係なく動作しますが、「JPAに依存しないプレーンなクラスである」ことを分かりやすくするため外しておきます。あわせて、採番されたIDをMyBatisがセットできるようsetId()を追加します。

変更前（JPA） 
package com.example.myapp.entity;

import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;

@Entity
public class Book {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String title;
    private String author;
    private Integer price;

    protected Book() {}
    public Book(String title, String author, Integer price) {
        this.title = title;
        this.author = author;
        this.price = price;
    }

    public Long getId() { return id; }
    public String getTitle() { return title; }
    public void setTitle(String title) { this.title = title; }
    public String getAuthor() { return author; }
    public void setAuthor(String author) { this.author = author; }
    public Integer getPrice() { return price; }
    public void setPrice(Integer price) { this.price = price; }
}
変更後（MyBatis） 
package com.example.myapp.entity;

public class Book {
    private Long id;
    private String title;
    private String author;
    private Integer price;

    public Book() {}
    public Book(String title, String author, Integer price) {
        this.title = title;
        this.author = author;
        this.price = price;
    }

    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }  // MyBatisが採番後のIDをセットするために必要
    public String getTitle() { return title; }
    public void setTitle(String title) { this.title = title; }
    public String getAuthor() { return author; }
    public void setAuthor(String author) { this.author = author; }
    public Integer getPrice() { return price; }
    public void setPrice(Integer price) { this.price = price; }
}

⑤ repository/BookRepository.javaを削除し、BookMapperを作成する

repository/BookRepository.javaを削除し（repositoryフォルダも不要になれば削除してください）、代わりに次の2ファイルを作成します。

新規：mapper/BookMapper.java（src/main/java/com/example/myapp/mapper/） 
package com.example.myapp.mapper;

import com.example.myapp.entity.Book;
import org.apache.ibatis.annotations.Mapper;
import java.util.List;

@Mapper
public interface BookMapper {
    List<Book> findAll();
    Book findById(Long id);
    int insert(Book book);
    int update(Book book);
    int deleteById(Long id);
}
新規：BookMapper.xml（src/main/resources/mapper/） 
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
  "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.myapp.mapper.BookMapper">

  <select id="findAll" resultType="Book">
    SELECT * FROM book
  </select>

  <select id="findById" resultType="Book">
    SELECT * FROM book WHERE id = #{id}
  </select>

  <insert id="insert" useGeneratedKeys="true" keyProperty="id">
    INSERT INTO book (title, author, price)
    VALUES (#{title}, #{author}, #{price})
  </insert>

  <update id="update">
    UPDATE book
    SET title = #{title}, author = #{author}, price = #{price}
    WHERE id = #{id}
  </update>

  <delete id="deleteById">
    DELETE FROM book WHERE id = #{id}
  </delete>

</mapper>

⑥ MyAppApplication.javaに@MapperScanを追加する

変更前 
@SpringBootApplication
public class MyAppApplication {
    public static void main(String[] args) {
        SpringApplication.run(MyAppApplication.class, args);
    }
}
変更後 
import org.mybatis.spring.annotation.MapperScan;

@SpringBootApplication
@MapperScan("com.example.myapp.mapper")
public class MyAppApplication {
    public static void main(String[] args) {
        SpringApplication.run(MyAppApplication.class, args);
    }
}

⑦ service/BookService.javaを書き換える

呼び出し先がbookRepositoryからbookMapperに変わります。save()のようにINSERT/UPDATEを自動判別するメソッドはないため、登録はinsert()、更新はupdate()とメソッドを分けて呼び出します。

変更前（JPA） 
package com.example.myapp.service;

import com.example.myapp.form.BookForm;
import com.example.myapp.entity.Book;
import com.example.myapp.exception.ResourceNotFoundException;
import com.example.myapp.repository.BookRepository;
import org.springframework.stereotype.Service;
import java.util.List;

@Service
public class BookService {

    private final BookRepository bookRepository;

    public BookService(BookRepository bookRepository) {
        this.bookRepository = bookRepository;
    }

    public List<Book> findAll() {
        return bookRepository.findAll();
    }

    public Book findById(Long id) {
        return bookRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("id=" + id + "の本が見つかりません"));
    }

    public Book create(BookForm form) {
        Book book = new Book(form.getTitle(), form.getAuthor(), form.getPrice());
        return bookRepository.save(book);
    }

    public Book update(Long id, BookForm form) {
        Book book = findById(id);
        book.setTitle(form.getTitle());
        book.setAuthor(form.getAuthor());
        book.setPrice(form.getPrice());
        return bookRepository.save(book);
    }

    public void delete(Long id) {
        Book book = findById(id);
        bookRepository.delete(book);
    }
}
変更後（MyBatis） 
package com.example.myapp.service;

import com.example.myapp.form.BookForm;
import com.example.myapp.entity.Book;
import com.example.myapp.exception.ResourceNotFoundException;
import com.example.myapp.mapper.BookMapper;
import org.springframework.stereotype.Service;
import java.util.List;

@Service
public class BookService {

    private final BookMapper bookMapper;

    public BookService(BookMapper bookMapper) {
        this.bookMapper = bookMapper;
    }

    public List<Book> findAll() {
        return bookMapper.findAll();
    }

    public Book findById(Long id) {
        Book book = bookMapper.findById(id);
        if (book == null) {
            throw new ResourceNotFoundException("id=" + id + "の本が見つかりません");
        }
        return book;
    }

    public Book create(BookForm form) {
        Book book = new Book(form.getTitle(), form.getAuthor(), form.getPrice());
        bookMapper.insert(book);  // 実行後、book.getId()に採番されたIDが入る
        return book;
    }

    public Book update(Long id, BookForm form) {
        Book book = findById(id);  // 存在しなければここで例外が投げられる
        book.setTitle(form.getTitle());
        book.setAuthor(form.getAuthor());
        book.setPrice(form.getPrice());
        bookMapper.update(book);
        return book;
    }

    public void delete(Long id) {
        findById(id);  // 存在しなければここで例外が投げられる
        bookMapper.deleteById(id);
    }
}

⑧ 動作確認

controller/BookController.java・form/BookForm.java・exception/ResourceNotFoundException.java・exception/GlobalExceptionHandler.java・test.htmlは変更不要です。そのままの状態で動作確認します。

  1. VSCodeのターミナルで mvn spring-boot:run、または IDEの実行ボタンからメインクラスを実行する
  2. ブラウザで http://localhost:8080/test.html にアクセスし、Spring Boot編と同じ画面から一覧取得・詳細取得・新規登録・更新・削除を試す
おまけ
http://localhost:8080/h2-console（JDBC URL：jdbc:h2:mem:testdb）から、schema.sqlで作成されたbookテーブルの中身を直接確認できます。
